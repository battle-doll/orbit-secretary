# Orbit Secretary (궤도 조정자)

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [Русский](README.ru.md)

**複数の Codex タスクを、ひとつの会話で。あなたが決めた方向へ。**

> 無数のタスクがそれぞれの軌道を巡るとき、互いに衝突しないよう見守り、判断し、軌道を調整する存在。

![Orbit Secretary: ひとつの会話で選んだタスクを観測し、話し合い、調整する秘書](assets/social-card.png)

Orbit は、長期にわたる複数の Codex タスクを進める人のための秘書です。ひとつの会話で報告を受け、どこに注力するかを決め、選んだタスクへその方向を伝える役割を任せられます。

## Orbit でできること

- **ひとつの場所で状況を把握する。** 会話をひとつずつ開かずに、何が変わり、何が終わり、どんな判断が必要なのかを確認できます。
- **時間を使う先を決める。** 優先順位、先行する作業、残りの労力に対する期待効果を比較できます。
- **決めたことを作業に反映する。** 時間と追加指示の回数に上限を決め、合意した指示を選んだタスクに送る役割を任せられます。

## Observe · Discuss · Act

| モード | 任せられること |
|---|---|
| **Observe — 報告を受ける** | 進捗、成果、障害、確認できなかった内容をまとめます。読み取りと報告だけでは、タスクへの指示は送りません。 |
| **Discuss — 方向を決める** | 次の手順、アーキテクチャの選択肢、さらに取り組む価値があるかを比較します。どのタスクをどう調整するかはユーザーが決めます。 |
| **Act — 選んだタスクを調整する** | 委任された追加指示を送り、受け付けられた内容と、タスクで実際に確認された結果を報告します。 |

## 始め方

Orbit をインストールしたら、報告を受け取りたい Codex の会話またはプロジェクトを開き、そこで `$orbit` を呼び出してください。

```text
$orbit 今日の作業と、私の判断が必要な内容をまとめて。
```

あとは自然に会話を続けられます。

```text
Orbit、この中で最初に確認すべきタスクはどれ？ 理由も教えて。
Orbit、このタスクを続ける場合と、範囲を縮める場合を比較して。
Orbit、今選んだタスクに、未決の事項を整理するよう一度だけ指示を送って。
```

1. **報告を確認する。** 最初の報告は、ユーザーのタイムゾーンの今日 0 時から始まります。以後は、確認済みの前回の報告を起点にします。収集できなかった情報も Orbit が伝えます。
2. **調整する作業を選ぶ。** 報告の中から選ぶか、対象のタスク名を伝えてください。Orbit は何かを送る前に対象を特定します。
3. **任せる範囲を決める。** 目標、許可する指示、制限時間、追加指示の回数を合意します。Orbit は現在の会話でその範囲の調整を行い、結果を報告します。

報告と相談だけに使うこともできます。追加指示を任せるかどうかは自由です。

## 好きな名前で呼ぶ

`$orbit` を呼び出した後、その会話で使う別名を付けられます。新しい会話では、別名を使う前にもう一度 `$orbit` を呼び出してください。

## 利用時に知っておくこと

- **範囲はユーザーが決めます。** Orbit が調整するのは、選んだタスクです。ユーザー自身が行うべき判断や承認を代行しません。
- **調整は現在の会話で行います。** 席を外している間に定期的に動くバックグラウンド管理機能は含まれません。
- **プラグインをオフにしても、送信済みの仕事は取り消されません。** すでに届いた指示や実行中のタスクは、自動ではキャンセルされません。進行中のタスクを止める場合は、Codex のタスク制御を使ってください。
- **利用できる機能は Codex の環境によって異なります。** 別のタスクを読んだり調整したりするには、Codex がその機能を提供している必要があります。利用できない機能は Orbit が説明し、ユーザーが提供した資料で手伝うこともできます。
- **指示の送信とタスクの完了は別です。** Orbit は受付、タスクの応答、確認できた結果を分けて報告します。不足している情報も明示します。

報告や委任については、[機能の詳細](docs/PUBLIC_SCOPE.md)もご覧ください。

## 利用環境・費用・プライバシー

Orbit は **macOS、Windows、Linux の Codex 環境**向けです。別のサービスを設定することなく、Codex 内でそのまま使えます。

報告と追加指示には Codex の利用枠を使います。ROI を相談するときは仮定を明示し、調整そのものにかかる時間と費用も考慮します。

Orbit には、提供者が運営する独自のバックエンドや利用情報の収集サービスはありません。タスクの内容は Codex と設定されたモデルを通じて処理され、報告は会話内、またはユーザーが選んだワークスペースに残ります。
